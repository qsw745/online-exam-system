# 问衡 iOS 阶段二：账号与区域实施计划

> 日期：2026-08-30
> 状态：本地实现与验证完成

## 目标

把“地区”从界面偏好提升为不可绕过的账号与服务边界，并补齐稳定用户标识、个人注册年龄门槛、登录区域校验、应用内注销和区域化 API 选择。阶段二完成只表示代码与本地验收通过，不代表中国大陆/海外物理部署、生产迁移或法律材料已经完成。

- [x] 后端增加 `CN | GLOBAL`、ISO 国家代码、年龄段和个人注册策略纯函数。
- [x] 前端增加地区选择、持久化和区域 API 地址解析纯函数。
- [x] 先写失败测试，再实现策略；覆盖大陆未满 14 周岁阻断、国家/地区不匹配和安全默认值。

- [x] 为 `organizations` 增加不可随意切换的 `data_region`。
- [x] 新建 `user_identities`、`guardian_consents`、`account_deletion_requests`，定义唯一键、审计字段和保留状态。
- [x] 迁移只写入代码并通过静态加载检查；本轮不修改生产数据库。

## Task 3：把区域写入注册、登录和令牌

- [x] 注册必须提交地区、国家或地区和出生日期；服务端应用年龄门槛后再创建账号。
- [x] 新账号生成稳定 `public_id`，同步邮箱身份记录。
- [x] 登录在密码验证成功后校验请求区域，避免通过区域错误枚举账号。
- [x] access/refresh token 携带地区；区域服务拒绝跨区令牌。
- [x] 兼容迁移前数据库，但生产模式缺少区域列时明确失败而不是静默降级。

## Task 4：移动端地区化登录与注册

- [x] iOS 登录和注册显示中国大陆/海外地区选择；Web 后台保持原路径。
- [x] HTTP 客户端按当前地区选择 `VITE_API_URL_CN` 或 `VITE_API_URL_GLOBAL`，缺失时回退 `VITE_API_URL`。
- [x] 登录成功后锁定到账号地区；区域不匹配显示可操作错误，不自动跨区重试密码。
- [x] 注册协议链接使用真实路由，不保留 `href="#"`。

## Task 5：应用内账号注销闭环

- [x] iOS“我的”提供保留范围说明、密码重新认证、明确确认词和结果页。
