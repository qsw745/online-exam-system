> 执行日期：2026-09-01
> 结论：数据生命周期与账号删除闭环已完成本地实现、自动化回归、375×667/393×852 响应式闭环验收、Capacitor 同步和 iOS 无签名通用模拟器构建；尚未执行真实数据库迁移、真实数据删除、真机、预发布/生产、TestFlight 或 App Store 操作。

## 已实现能力

- 支持立即删除和 30 天宽限两条注销路径；申请前展示删除、匿名化和条件保留范围，宽限期执行前可重新认证取消。
- 客户端先生成规范请求编号和 32 字节高熵状态令牌；服务端只保存摘要。网络结果不确定时复用同一请求编号、模式和令牌。
- iOS 登录会话与注销状态凭证使用独立 Keychain 槽位；注销后清理登录会话但保留状态凭证，公开状态页可在账号行删除后继续查询。
- MySQL 迁移定义了策略、账号注销父记录、期限扫描父记录、步骤、租约、合法冻结、管理操作幂等账本、匿名主体、回执、墓碑和加密消息箱。
- 生命周期 Worker 使用固定处理器注册表、小批量游标、租约、过期接管、指数退避和失败关闭；未知表、未知处理器和身份反向关联会阻断完成。
- 账号删除前依次处理认证/人脸凭据、资料、学习数据、考试档案匿名化、监考数据隔离、关系和日志；账号删除与墓碑同步位于不可逆流程末端。
- 合法冻结、期限延期、全局暂停、恢复、单步重试和安全预演受区域与权限约束；管理接口不提供强制完成或任意 SQL。
- 最终通知使用加密消息箱，发送成功后清理密文，失败消息最多保留 7 天；墓碑可在旧备份恢复后重放。

## 隔离生命周期契约测试

本轮没有可用的隔离 MySQL，因此新增的是事务化内存契约测试，不把它写成真实 MySQL 验证。测试复用真实 `AccountDeletionService`、生命周期 Worker、状态推导、数据覆盖审计、期限判断和墓碑服务，覆盖：

1. 立即注销执行到去身份完成状态，认证/人脸凭据删除，考试与监考记录解除原用户关联，状态响应不暴露内部身份或原始令牌。
2. 30 天计划时间前不执行且可以重新认证取消。
3. Worker 暂时故障恢复、租约过期接管和同一步骤并发竞争。
4. 未知用户关联列、未知处理器失败关闭；期限扫描遵守到期时间与有效冻结。
5. 通知密文清理、删除墓碑生成和旧备份恢复后的墓碑重放。

没有运行 `db:latest`、真实 `privacy:schema-audit`、生命周期 Worker、消息 Worker 或邮件进程。

## 手机端闭环验收

Playwright 在 375×667 与 393×852 两个视口使用“本地模拟 API + 模拟 Keychain 桥接”。接口采用与生产相同的成功/失败信封、注销模式和状态枚举；所有账号、状态和处理结果均为固定夹具，不代表删除了真实数据。

每个视口均验证：

1. 立即删除首次请求被主动中断后，页面保存恢复凭证并显示结果不确定提示；重试复用完全相同的请求编号、状态令牌和模式。
2. 请求成功后清理登录会话，保留注销状态凭证，进入公开状态页并显示 `COMPLETED_WITH_RESTRICTED_RETENTION` 及受限保留用途说明。
3. 关闭页面并新建文档后，仍可从模拟 Keychain 恢复处理状态和步骤明细。
4. 30 天模式显示宽限提示和 `SCHEDULED` 状态，可重新输入邮箱密码取消，并清除状态凭证返回登录页。
5. 无本机凭证时可通过邮箱密码恢复查询已完成状态。
6. 页面无横向溢出，底部导航不再遮挡注销提交按钮。

意外应用控制台错误为 0。主动中断请求时 Chromium 会产生 1 条预期的 `net::ERR_FAILED` 资源诊断，测试对其数量做精确断言；除该故障注入证据外没有其他控制台错误或页面异常。

首轮 E2E 实际发现并推动修复：

- iOS 手机壳的固定底部导航覆盖注销提交按钮，现为 `.mobile-app-shell` 增加导航高度、安全区和额外滚动余量。
- 注销成功后先清会话会触发登录守卫抢先跳转，现改为先进入公开注销状态页，再清理会话。
- 受限保留日期在单列 `Descriptions` 中使用双列跨度会触发布局警告，现改为响应式安全的单项布局。
- Vitest 默认加载 Playwright `*.spec.ts`，现限制为 `src/**/*.test.{ts,tsx}`，保证两套测试职责分离。

## 隐私字段自审

- 管理端生产类型和页面不包含原始 `statusToken`、邮箱、手机号或 `anonymousSubjectId`；搜索命中的邮箱/手机号仅在脱敏防回归测试夹具中。
- 生命周期服务中的邮箱只用于配置占位检查、重新认证或在删除事务内生成加密通知信封；管理 API、回执和日志不返回明文。
- 匿名主体编号只存在于内部迁移/处理器 SQL 和测试断言，不写入注销请求、回执、墓碑或管理端响应。
- 完成关联断言要求保留记录清空原 `user_id`，并测试回执、状态响应和墓碑不存在原身份到匿名主体的可逆连接。
